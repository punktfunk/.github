<p align="center"><b>Low-latency desktop and game streaming with first-class Linux and Windows hosts.</b></p>

Run the host on a Linux or Windows PC and stream your desktop or games to a Mac, PC, phone, tablet
or TV. Each client gets its own virtual display at its own native resolution and refresh rate.

- **[punktfunk](https://github.com/punktfunk/punktfunk)**: host, console and native clients
- **[client-web](https://github.com/punktfunk/client-web)**: browser client
- **[client-webos](https://github.com/punktfunk/client-webos)**: LG webOS TV client
- **[client-tizen](https://github.com/punktfunk/client-tizen)**: Samsung Tizen TV client
